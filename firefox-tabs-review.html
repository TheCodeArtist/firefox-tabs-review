Help and shortcuts

then open, select, copy, or export reloadable tab snapshots with minimal clicks.

Search and Filtering

  • Search matches tab title, URL, domain, Firefox profile, and container.
  • Toolbar filters cover profile, container, age, and window. View controls cover grouping, sorting, and density.
  • Insights uses the same filters: containers, age buckets, top domains, and duplicate URLs.
  • Active chips summarize search, filters, duplicate URL, and non-default view settings.
  • Use the Groups menu to expand or collapse all groups in the current grouping mode.

Command Navigation

Press Ctrl K or click Command.
Type part of a command, pick with ↓ / ↑, then press Enter.

window 2 container Work group domain sort newest clear filters theme insights export json reset viewer

Selection and Export

  • Click a row or use the keyboard to set the active tab. Double-click opens it.
  • Select tabs with checkboxes or x. Use Shift x for a contiguous range.
  • The bulk bar can open selected tabs, copy URLs, copy Markdown, or copy OneTab format.
  • Export JSON downloads a reloadable snapshot with favicons. Drop it back in to reload later.
  • Right-click a row to open, copy URL, copy title, copy Markdown, or filter by domain.
Tip: Command searches the current filtered results, so it works as a fast jump list. The last loaded tab list, favicons, and preferences are saved locally in this browser for refresh/reopen.
